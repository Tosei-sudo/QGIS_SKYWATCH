どの担当でも使う操作

ドックを出す・片付ける

  • ドックはメニューかツールバーのボタンで開きます。もう一度押すと前面に出ます
  • ドックが見つからない・画面の外に行ってしまったときは、メニュー ドックを初期位置に戻す
  • 作業ごとの並びを覚えさせるには、メニュー ドックのレイアウト ▸ 現在の配置を保存…。名前を付けて保存すると、次から 1 回で切り替えられます。「撮像計画の担当」「撮像を依頼する人」「観測記録の担当」「画像判読」「AI 学習の担当」「判読練習の指導者」の例も最初から入っています

一覧を見やすくする

ドックの一覧は、見出しを右クリックすると列を出したり隠したり、順番を変えたりできます。右クリックした列は この列を左へ・この列を右へ・この列を先頭へ・この列を末尾へ で動かし、まとめて変えるときは 列の表示と順番… でチェックと 上へ・下へ を使います（見出しのドラッグでも動かせますが、設定ファイルでドラッグを止めている場合はメニューだけです）。並びは一覧ごとに覚えます。最初は隠れている列もあります（撮像依頼・撮像予定・撮像計画ファイル出力・計画と実績の照合の メモ は、依頼のメモを 1 行で出す列です。長いメモはセルにマウスを置くと全文が出ます）。チェックを入れると出て、次からもそのままです。標準の表示に戻す で、列はプラグインの順番に戻り、最初は隠れている列はまた隠れます。画像カタログ・観測記録・撮像依頼の一覧の横の ビュー では、今の見え方（列・並べ替え・絞り込み）に名前を付けて保存し、あとで 1 回で戻せます。どれもあなたの PC だけの設定で、ほかの人には影響しません。

画像を探して開く（画像カタログ）

画像カタログ ドック（Ctrl+Alt+I）で、届いた衛星画像を探します。

  1. 範囲を選ぶ。既定は今の地図の表示範囲。範囲を描く で多角形を描く（クリックで頂点、ダブルクリックか右クリックで確定、Esc で取り消し。描いている途中の形も地図に出ます）、レイヤー で選んだレイヤーの形とも重ねられます。描いた範囲は横の 保存… で名前を付けて保存でき、次からは範囲を 保存した範囲 にして一覧から選べます（新しい順。選んだ範囲は地図に緑の破線で出て、見えない場所ならそこへ地図が移ります。編集 で範囲へ移動・名前の変更・削除。保存先はあなたの PC だけです）
  2. 撮像日時を入れ（2026-11-09 のほか 2026/11/9・20261109・全角の数字でも可。日付だけならその日いっぱい。時刻をつけると分の単位で絞れます: 2026-11-09 10:30 〜 2026-11-09 12:00 は 10:30 から 12:00 台の終わりまで。右に 12:00 と時刻だけ書けば左と同じ日。時刻はこの PC の時刻で、一覧の撮像日時と同じです。読めない日付・時刻は検索せずに知らせます）、必要なら 詳細条件 でセンサー・角度などを絞る（センサーは「、」で区切って複数でも。どれかのセンサーの画像を探します。文で操作 で「SAR画像」と書くと SAR のセンサーが入ります）。フリーワード 欄では、画像 ID の一部や、備考などに含まれる語でも探せます（画像 ID はどのカタログでも対象。空白で区切ると、すべての語を含む画像。大文字・小文字、ひらがな・カタカナ、全角・半角は区別しません。Enter でも検索）
  3. 検索。一覧は新しい順。行を選ぶと地図にその画像の範囲（橙）が出ます。多いときは新しい 500 件（数は設定ファイルによる）までで、状況欄に「1234 件中 新しい 500 件」と出ます。一覧の下の 続きを読む で、同じ検索のもっと古い画像を足せます
  4. 開く かダブルクリックで、画像がレイヤーとして地図に入り、地図がその画像の範囲へ移ります（何枚も開いたときは、すべてが入る範囲。レイヤーの名前は画像 ID）
  • ボタンは幅に合わせて折り返して並び、その下に開くときのオプション（前の画像を閉じる・開いた画像へ移動・投影法を画像に合わせる・向き・フットプリント）が 1 行に 1 つずつ並びます
  • 一覧を順に見ていくときは、ボタンの下の 前の画像を閉じる にチェック。次の画像を開くと、その前にここから開いた画像は地図から外れます（チェックは次回も残ります）。その画像の AI 結果のレイヤー（AI結果 ドックが出す結果、物体検出（AI）・似たものを探す の結果）と、それで空になったグループも一緒に消えます。編集中で保存していない結果・ほかの画像の結果も入っているレイヤー・ほかのレイヤーが残っているグループ・一番上に固定 したグループはそのままです
  • ファイルに保存していない（一時レイヤーの）検出結果は、消えると元に戻りません。残したい結果は、次の画像へ進む前に観測記録に取り込むか、ファイルに保存します（取り込んだ記録は残ります。検出をやり直せば作り直せます）
  • 開いても地図を動かしたくないとき（拡大した場所のまま別の日の画像を重ねるときなど）は、開いた画像へ移動 のチェックを外します
  • 画像を画像と同じ投影法で見たいときは、投影法を画像に合わせる にチェック。開くたびに地図の投影法がその画像の座標系になります（経緯度の画像や、GCP・RPC で置かれた画像は、画像の中心の UTM 帯）。何枚も一度に開いたときは一覧で最初の画像に合わせ、ほかのレイヤーは QGIS が変換して重ねます（位置はずれません）
  • 北が上ではなく、撮ったときの向きで見たいときは 向き を選びます。撮像方向が上（衛星が下） は衛星から地上を見る向きが上（光学の斜め撮りではビルが上へ倒れて見えます）、衛星が上（撮像方向が下） は衛星が画面の上（SAR の影が下へ伸びます）、進行方向が上（SAR） は衛星の進む向きが上です。向きはカタログの方位角、クイック幾何補正で入力した衛星の方角、画像のメタデータの順に探します。わからないとき・ほぼ真下から撮った光学画像は北が上のままで、理由がドックの下に出ます。開いたあとで向きを変えるときは、画像補正 ドックの上の 地図の向き のボタン（N・撮・衛・進）で回せます
  • 地図が回っている間は、地図の右上に北の矢印が出ます。矢印をクリックすると北が上に戻ります。向きや投影法を変えた画像をすべて閉じると、開く前の投影法と回転に戻ります（途中で自分で変えたものは戻しません）。地図が回っていても、観測記録の記録・ドラッグ・2 点で測る・座標の表示は今までどおりで、記録の向き（°）も北から測ります
  • 地図の範囲（フットプリント）が画像の邪魔なときは、ボタンの下の フットプリント で 枠だけ（ふだんはこれ）・塗りつぶし・非表示 を選べます。非表示でも 地図で選択 のクリックで選べます
  • 初めて開くとき「〇〇のフォルダの選択」という画面が開いたら、画像が置いてある共有フォルダを選びます（次からは覚えています）
  • 画像のファイルをエクスプローラーで見たいときは、選んで フォルダを開く。画像のあるフォルダが開き、そのファイルが選ばれた状態になります（フォルダの画像はそのフォルダ）。パスの読み替えを設定している職場では、読み替えた先のフォルダが開きます
  • 画像 ID がわかっているときは、ドックのいちばん上の 画像 ID で開く 欄に貼って Enter。検索の条件を入れなくても、その画像が開きます
  • 一度開いた画像は、この PC が覚えています（画像 ID・カタログ・開いたファイル。最近の 300 枚）。同じ画像をもう一度開くときは、カタログに問い合わせずに 前回のファイルで開く の確認が出ます。前回開いたファイルにチェックが付いているので、そのまま Enter（違うファイルにするならチェックを変える）。ファイルが移動して見つからないときは カタログで探し直す。最近開いた画像 ボタンからも同じように開けます
  • 生データが別のシステムにしかない画像（カタログだけある画像）は、選んで ファイルなしで記録。画像 ID・撮像日時・範囲がそのまま観測記録に入り、地図がその場所へ移るので、背景地図の上をクリックして記録します（複数選べば ◀ ▶ で順に）。そういう画像だけのカタログでは、開く の代わりにこのボタンが出ます。ふつうのカタログでも、画像が開けなかったときはメッセージの横に出ます
  • ファイルなしで記録している画像は、レイヤー一覧のいちばん上のグループ ファイルなしの画像 に、フットプリントの紫の枠のレイヤーとして 1 枚ずつ入ります（記録中の画像は太い線）。レイヤーを選ぶとその画像に切り替わります。終わった画像は、開いた画像を閉じるのと同じように、そのレイヤーを削除すると観測記録の一覧から外れます（記録は残ります）。前の画像を閉じる にチェックがあれば、次の画像を ファイルなしで記録 したとき（開いたときも）、前にここから入れた画像が一覧と地図から自動で外れます（記録は残ります）。画像ファイルのないカタログでも、このチェックが出ます
  • 分担を使っている職場では、一覧の最後の列に「未着手」「作業中（名前）」などが出ます。未着手のみ で、まだ誰も手を付けていない画像だけにできます
  • 画像の評価 を使っている職場では、その隣の列 評価 に「使える」「使えない」「一部（使えない 1/3）」などが色付きで出ます（地名ごとの内訳はマウスを置くと出ます）。見出しのクリックで並べ替え
  • 同じ条件で新しい画像を待ちたいときは この条件で監視…。新着は 通知 ドックに出て、ツールバーの「通知」に未読数が付きます。地図の右クリック「この地点の新着画像を監視…」でも作れます。条件に合う画像は、監視を作ったときにすでにあったものもすべて一覧に入ります（既読で、「設定前から」と出ます）
  • 港や基地など、決まった場所の形で見張りたいときは、監視の範囲で レイヤー を選び、その場所のレイヤーを選びます（一部だけなら地物を選んで 選択地物のみ）。監視はそのときの形を写して覚えるので、あとでレイヤーを直したら、通知ドックの「監視条件」タブで監視を選んで 範囲の変更… を押し、取り直します

入ってきた画像を順に見る（新着画像）

監視で見つかった画像は、地図の場所いっぱいの 新着画像（大きな画面）（Ctrl+Alt+N、メッセージバーの「新着画像 n 件」の 見る でも）で、カードにして順に見られます。地図の上に「地図｜新着画像」のタブが出るので、タブで地図と行き来します。

  • カードは見つかった順に上から並び、いちばん下がいちばん新しい画像です。監視を作る前からあった画像も、登録された順にその上に並びます（既読で、「監視の設定前から」と出ます）。最初は、まだ見ていない（未読の）いちばん古いカードが出ます
  • 見ている間に新しい画像が来ても画面は動きません。右下に ↓ 新着 n 件 が出るので、押すとそのカードへ移ります
  • カードにはサムネイル、撮像日時・センサーなどの属性、画像ファイル、写っている地物（その画像の範囲にある港や施設などの名前。レイヤーの見出しの下に 1 件 1 行で、すべて出します。種別などで行に色が付くこともあります）が出ます。画像ファイル には、その画像で開けるファイル（フォルダの画像なら全部）がチェックボックス付きで並びます。クリックでチェックを付け外しし、開く でチェックしたファイルを開きます。ダブルクリックするとそのファイルだけ開きます。画面が広いときはサムネイル・属性・画像ファイル・写っている地物の 4 列、狭いときは属性の下に並びます。サムネイルや地物は設定ファイルにあるときだけです
  • 開く（カードのダブルクリックでも）で画像が地図に入り、地図に切り替わってその画像へ移ります。地図で見る は画像を開かずに範囲へ移ります。どちらも既読になります。見終わったら 新着画像 のタブで戻ります
  • 順に見ていくときは上の 前の画像を閉じる にチェック。次を開くと、前にここから開いた画像は地図から外れます（その画像の AI 結果のレイヤーと、空になったグループも）。未読のみ でまだ見ていないカードだけに、監視の欄で 1 つの監視だけにできます（どちらも、表示中のカードだけでなくすべての画像から選びます）
  • タブの × で閉じても、通知ドックはそのまま使えます（既読はどちらにも効きます。一覧から消すのは通知ドックの 削除 で）

自分の関心地域・地点

自分がいつも見ている港・基地・海域などを 関心地域・地点 ドックに入れておくと、新着画像のカードの写っている地物のいちばん上に、その画像に入っているものが自分の色で出ます。保存先はサーバーなので、別の PC でも同じものが出ます（ほかの人のものは出ません）。

  • 地点を追加 を押して地図をクリック、または 地域を追加 を押して地図で多角形を描きます（クリックで頂点、ダブルクリックか右クリックで確定、Esc でやり直し）。作業中のレイヤーで選んだ地物からは 選んだ地物から
  • 下に出る欄で名前を入れ、色とメモを決めて 保存（Enter でも）。保存するまでは地図に破線で出ます
  • 直すときは一覧で選んで同じ欄で。場所や形は 形を描き直す。消すときは選んで 削除
  • 地図に表示 で「関心地点」「関心地域」のレイヤーとして地図に出ます。オンのままなら次に QGIS を開いたときも出ます
  • 自分の地域を組織のものにするときは、選んで 組織の地域にする…。「組織」のタブに形と名前が入るので、カテゴリーなどを入れて 保存（自分の地域は残ります）

組織の関心地域

組織で見ている港・基地・海域などは、同じドックの 組織 のタブにあります。地名と同じ表に入っていて、だれでも追加・編集できます。新着画像のカードでは、自分の関心地域・地点の次に「組織の関心地域」として、その画像に入っているものが出ます。

  • 一覧は カテゴリー別・上位の地域別・一覧 で並べ替えられます。上の欄で名前・よみがな・別名・管理番号を入れて絞り込みます（用途は「関心地域」が既定。「地名」「すべて」で地名だけの行も出ます）
  • 新しく作るときは 新しい地域 を押して地図で多角形を描くか、作業中のレイヤーで面を選んで 選んだ地物から。下の欄で名前・よみがな・別名（カンマ区切り）・カテゴリー・国・担当グループ・重要度などを入れて 保存
  • 管理番号は空のままでかまいません。保存すると NA-000123 の形で自動で付きます（ほかの地域と同じ番号は保存できません）
  • 形を直すときは一覧で選んで 描き直す・選んだ地物から・頂点を直す（QGIS の頂点ツールで頂点を動かす・足す・消す。終わったらもう一度押す）
  • 用途が「関心地域」だけの地域は、通報や観測記録の場所の名前には使われません。地名としても使うなら用途を「両方」に
  • 使わなくなった地域は 有効 を外します（行は消しません）
  • カテゴリーは カテゴリー… で追加・変更・並べ替え（港湾 ▸ 軍港 のような木）。地域があるカテゴリーは消せないので、使わなくなったら有効を外します
  • 地図に表示 で「組織の関心地域」のレイヤーとして地図に出ます
  • 選んだ地域の撮像依頼は 撮像依頼…（名称・範囲・依頼グループ・優先度が地域のもので入ります。くわしくは 撮像依頼を登録する の「組織の関心地域から作るとき」）。依頼 の列はその地域の有効な依頼の数で、依頼がつながっている地域の管理番号は変えられません。地域の形を直して保存すると、つながる依頼の範囲も合わせます（地域の形が変わったとき）

場所へ移動する

  • ツールバーの「座標・地名へ移動」の欄に座標（35.6812, 139.7671・35°40'52"N 139°46'1"E・MGRS など）を入れて Enter。地名が使える設定なら、地名や住所も入れられます（候補から ↑↓ と Enter で選ぶ）
  • 地図の右クリック 緯度経度・MGRS・UTM のコピー で、その地点の座標をコピー
  • 背景の地図はツールバーの 背景地図 で切り替え（「なし」で消す）
  • ブラウザで読んでいる文書の座標は、拡張機能 AutoMap の MIKAGE ボタン（サイドパネルの一覧・地図のタブ）か、ハイライトされた座標の Shift+クリックで MIKAGE に送れます。送った点・線・面はレイヤーパネルの「受け取った図形」に入り、地図がそこへ移動します（QGIS を起動しておく。いらなくなったらレイヤーを削除）

レイヤーをいつも一番上に出す（一番上に固定）

境界・地名・作業中の図形など、画像を開いても隠したくないレイヤーは、レイヤーパネルで右クリックして 一番上に固定。レイヤー名の横にピンの印が出て、いつもレイヤーパネルの一番上（地図ではいちばん手前）に置かれます。

  • 新しく開いた画像やレイヤーは、固定したレイヤーのすぐ下に入ります（固定でないレイヤーを選んでいれば、いつもどおりそのレイヤーの上）
  • いくつか選んでまとめて固定できます。グループも固定できます。固定したものどうしの順番はドラッグで入れ替えられます
  • 外すときは、もう一度右クリックして 一番上に固定（チェックが外れます）。レイヤーはその場に残ります
  • 固定はプロジェクトに保存され、開き直しても固定のままです

既存のレイヤーに地物を足す（アペンド）

ほかのレイヤーの地物を、すでにあるレイヤー（ArcGIS のフィーチャレイヤーも）に足せます。ArcGIS の「アペンド」と同じ操作です。メニューの アペンド（既存レイヤーへ追加）…（処理ツールボックスの「MIKAGE › レイヤー」にもあります）。

  1. 入力 で足したい地物のレイヤーを選んで 入力に追加（いくつでも）。選択した地物だけにするときは、その行の 選択した地物のみ にチェック。式で絞り込むこともできます
  2. 追加先 を選びます。プロジェクトのレイヤー、設定ファイルにある ArcGIS の表、または ArcGIS フィーチャレイヤーの URL を入力…（…/FeatureServer/0）
  3. フィールドマップ で、追加先の列ごとに入れる値を確かめます。はじめは列名で合わせてあります。セルをダブルクリックすると、入力の列（いくつか選んで連結・合計・平均なども）、式、固定値、空を選べます
  4. 内容を確認 で、地物ごとに「追加」「更新」「飛ばす」と理由が出ます（まだ書き込みません）。型・文字数・ドメイン（選べる値）・必須の列・形状の種類が合わないものは飛ばします
  5. 追加を実行。間違えたときは、画面を閉じる前なら 今回の追加を取り消し で元に戻せます
  • 同じ地物を入れ直すときは キー列が一致する地物は更新 にチェックしてキー列を選ぶと、同じキーの地物は更新され、ないものだけが追加されます
  • よく使う対応は フィールドマップ ▾ の 名前を付けて保存… で残せます（ファイルへの書き出し・読み込みもできます）。同じ追加先を選ぶと、前回の対応が戻ります
  • 座標系は追加先に合わせて変換されます。ArcGIS へ送ると、作成者・更新者もミカゲのほかの書き込みと同じように記録されます
  • 観測記録・撮像依頼台帳などミカゲ自身の表へは、「管理」の担当だけが追加できます

イベント（地震などの対応）にまとめる

地震・風水害・事故などの対応で使った画像・観測記録・撮像依頼を、ひとつのイベントにまとめておけます。メニューかツールバーの イベント。

  • 新規… で名前・種別・期間・範囲を入れて作る
  • 画像カタログ・観測記録・撮像依頼の一覧で選んで イベントに追加（Ctrl・Shift + クリックで複数まとめて）
  • イベントを選んで 地図に表示・画像を検索（イベントの期間と範囲で画像カタログを検索）・概要をコピー（報告や引き継ぎに貼る）
  • 対応が終わったら 終了。削除 はイベントとまとめの情報だけを消します（画像・記録・依頼そのものは残ります）
  • 下のタブ 参考情報: このイベントに紐付けた 参考情報。紐付け…・参考情報で表示・外す

参考情報（出典つきの情報）を残す

画像の外から知った情報（発表・航行警報・報道・ほかの部署からの通報など）を、出典と確からしさをつけて、場所と日時で残します。判読する人が画像を選ぶと、その場所・その頃の情報の数が出ます（画像・記録の参考情報）。メニューかツールバーの 参考情報。

  • 一覧は出来事の日時がこの期間（ふだんは 30 日）のもの。題名・要旨・出典で絞り込み、地図の範囲だけ で地図に見えている場所のものだけにできます。ドックを出している間、一覧の参考情報が地図に青い点で、選んだものがオレンジの点で出ます
  • 新規…: 題名・出来事の日時（発表の日時ではなく、起きた・見られた日時）・発表日時・出典（前に入れた出典が候補に出ます）・文書番号か URL・確からしさ（確定・推定・不明）・要旨・分類・場所・メモ
  • 場所は、窓を開いたまま 地図をクリック、地名から…（地名や組織の関心地域を選ぶと、その中の点と地名の両方が入ります）、地図の中心（新規のはじめ）
  • 地図へ で地点へ移動、URL を開く で元の記事・文書を開く、概要をコピー で報告や引き継ぎに貼る数行を作ります
  • だれでも登録・編集できます。削除 は登録した人と管理者だけです（紐付けも消えますが、イベント・モノ・記録そのものは残ります）
  • 観測記録の記録・モノと、イベントに紐付けられます。同じ組をもう一度紐付けても 1 つのままです

参考情報を JSON から取り込む

航行警報の一覧やほかのシステムの出力など、たくさんの参考情報は JSON ファイルにしてまとめて登録・更新できます。ドック 参考情報 の JSON 取り込み…。

  1. ファイルを選ぶ… で JSON ファイルを選ぶと、すぐ試行します（いまの参考情報と照らし合わせるだけで、保存はしません）。行ごとに 新規・更新・変更なし・重複（飛ばす）・エラー と、変わる項目かエラーの理由が出ます。エラーと注意の行だけ で絞れます
  2. 取り込む（n 件） で保存します。エラーの行は取り込まず、残りを取り込みます。終わるとドックには取り込んだ参考情報だけが出ます（すべてに戻す で期間の一覧に戻ります）
  3. 保存できなかった行があれば理由が出ます。同じファイルをもう一度取り込めば続きから入ります（id のある行は更新、id のない行は重複として飛ぶため）

ファイルは { "defaults": { … }, "infos": [ { … }, { … } ] } の形で、infos の 1 つが参考情報 1 件です（10,000 件まで、UTF-8）。形を定めた JSON Schema はリポジトリの mikage/resources/schemas/reference-info.schema.json、見本は docs/reference-info/sample.json です。

キー中身
title題名（必須）
time出来事の日時（必須）。2026-11-24・2026-11-24T10:30・2026-11-24T10:30:00+09:00・…Z。タイムゾーンのないものは PC の時刻
id情報ID。同じ ID があれば更新、なければこの ID で追加。省くと新しい ID を付けて追加
published発表日時（形は time と同じ）
source・sourceRef出典、文書番号か URL
reliability確からしさ（確定・推定・不明など、確度と同じ言葉）
summary・note要旨、メモ
kind分類（船舶 > 支援船）
area地名の管理番号か、地名の名前・別名
lon・lat地点の経度・緯度（両方）
links紐付け。[ { "type": "event", "id": "…", "label": "…" } ]。type は event（イベント）・thing（モノ）・observation（観測記録）
  • 更新で変わるのはファイルに書いたキーだけです。"" か null で消せます（題名と出来事の日時は消せません）。紐付けは足すだけで、外しません
  • id のない行は、題名・出来事の日時（分まで）・出典が同じ参考情報が既にあれば重複として飛ばします。同じファイルを 2 回取り込んでも増えません
  • 場所は、lon・lat があればその点、なくて area があればその地名の中の点です（地名から… と同じ）
  • defaults の値は、各行に書いていないキーに入ります（同じ出典の情報をまとめて入れるとき。id・title・time・lon・lat・links は書けません）
  • エラーになるもの: 日時が読めない、経度・緯度の片方だけ、地名が見つからない・同じ名前の地名が 2 つ、文字が長すぎる（切りません）、同じ id が 2 回、知らないキー。確からしさ・分類が候補にないときは注意だけ出して取り込みます
  • 取り込んだ参考情報の登録者は取り込んだ人です（削除できるのはその人と管理者）

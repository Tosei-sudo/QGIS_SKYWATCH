最初にすること

1. 担当と個人設定を選ぶ

プラグインを初めて入れたときだけ「最初の設定」の画面が出ます。あとで変えるときは、メニュー 担当と個人設定… から開きます。

  • 担当: 撮像計画の担当・撮像を依頼する人・観測記録の担当・画像判読・AI 学習の担当・判読練習の指導者・管理者から、自分の作業をいくつでもチェックします。その作業のドックが開き、メニューとツールバーにはその作業の機能が並びます（ほかの担当の機能は出ません）。チェックした担当のドックで開き直す を外すと、ドックは今のまま
  • ドックの開き方: メイン画面にタブでまとめるか、ドックごとに別ウィンドウで開くか。モニターが 2 台あるなら、別ウィンドウにして片方へ寄せると地図を広く使えます
  • 記録者名: 観測記録に残るあなたの名前。初めは Windows のユーザー名（環境変数 USERNAME、分担や作成者に出る名前と同じ）が入っています。別の名前にしたいときだけ書き換えます（空欄にするとユーザー名に戻ります）。クリック数（観測記録で 1 件に打つ点の数）とカーソル位置の表記（10 進・度分秒・MGRS・UTM）もここで
  • 生成 AI の機能: 職場で「文章の手伝い」（この PC か社内のサーバーで動く生成 AI）を用意しているときに、使う を入れると、備考を整える・依頼文から下書き・ミカゲと話す などのボタンが出ます。初めは入っていません（使うかどうかは一人ずつ選びます）。用意がなければ選べません

「あとで」で閉じても、次から画面は出ません。

2. 設定ファイルを確かめる

どのサーバーを使うか、どの画像カタログを探すかなどは、管理者が用意した設定ファイルで決まります。多くの場合はプラグインに同梱されていて、何もしなくても読み込まれます。

  • QGIS の上のほうに黄色い帯（メッセージバー）で「問題 n 件」と出たら、その帯の 設定… を押して内容を見てください（担当が「管理者」でないときは、下の 管理者向け が開いて問題が並びます）。自分で直せないときは、画面を管理者に見せます
  • 設定ファイルの場所を指定するよう言われたときは、メニュー 設定… で、もらったパスか URL を入れて「読み込み」（担当が「管理者」でないときは 管理者向け を ▶ で開くと出ます）
  • サインインは多くの場合、設定ファイルで決まっています。ポータルが Windows の認証（IWA）なら、Windows にログオンしているだけで自動でサインインします。SAML のときは初回にブラウザーが開くので、いつものようにサインインしてください。「設定…」の サインイン の行に、サインインした名前が出ます
  • 設定ファイルにないサービスでサインインが要るときは、同じ「設定…」の 管理者向け の表（担当が「管理者」なら最初から出ています）でサービスごとに QGIS の認証設定を選びます（どれを選ぶかは管理者の指示に従ってください）

3. つながるか点検する（管理者）

担当 管理者 をチェックした人は、メニュー 接続と表の点検… で、設定ファイルにあるサービスに 1 回ずつ問い合わせられます。書き込みはしないので、いつ押しても大丈夫です。ほかの担当の人は、一覧が出ないときに管理者へ知らせてください。

  • 一番上の サインイン の行に、設定ファイルの signIn ごとにサインインできたかが出ます
  • 問題（赤）: その表は使えません。サインインできない・応答がない・必要な項目がない など
  • 注意: 一部の機能だけ働きません
  • OK: 使えます

問題があれば 結果をコピー を押し、メールなどに貼って管理者に送ってください。

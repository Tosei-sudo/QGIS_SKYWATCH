# エラーコード一覧（管理者向け）

> このファイルは `python3 scripts/build_help.py` が `mikage/core/errors.py` から作ります。直接は直さないでください。

画面の失敗の表示は「〇〇に失敗: 理由［E101］」の形です。利用者向けの原因と対処はヘルプ（メニュー「使い方（ヘルプ）…」の「エラーコード一覧」。検索欄にコードを入れると、その行に飛びます）にあります。ここには、管理者が確かめるところを足しています。

- サーバーの URL・サーバー自身のメッセージ・Python のエラーは画面に出さず、ログメッセージの「MIKAGE」タブと監査ログに残します。
- 監査ログでは、エラーの行の `detail.code` にコードが入ります（列は増やしていません。ファイルの形式とハッシュの鎖をそのままにするため）。原因ごとの件数は `detail.code` で数えられます。
- コードは別の原因に使い回しません。使わなくなったコードは `RETIRED` に残します。

## 通信・サーバー（E1xx）

| コード | 画面の表示 | 原因 | 対処（利用者） | 管理者が確かめること |
|---|---|---|---|---|
| E101 | サーバーに接続できない | この PC からサーバーにつながりません。ネットワークが切れているか、サーバーが止まっています。 | ネットワーク（有線・Wi-Fi・VPN）を確かめ、しばらくしてからやり直してください。サーバーが止まっている間も、右下に「⚠ オフライン作業中」と出ていれば作業を続けられます（保存したものは送信待ちになります）。続くときは、コードと時刻を管理者に伝えてください。 | ログメッセージの「MIKAGE」タブと監査ログに、相手の URL と詳しい理由がある。サーバー・プロキシ・ファイアウォールを確かめる。 |
| E102 | サーバーの応答がない（時間切れ） | 決まった時間のうちにサーバーが答えませんでした。混んでいるだけのこともあります（朝に大勢が一度に始めたときなど）。 | 1〜2 分待ってから、もう一度やり直してください。続くときは、コードと時刻を管理者に伝えてください。 | ログメッセージの「MIKAGE」タブと監査ログに、相手の URL と詳しい理由がある。ArcGIS Server のインスタンス数と応答時間（docs/admin/operations.md の「裏の処理中の画面のなめらかさ」）。 |
| E103 | サーバーの中でエラー | サーバーが要求を受け取りましたが、サーバーの中で処理に失敗しました。 | しばらくしてから、もう一度やり直してください。続くときは、コードと時刻を管理者に伝えてください。 | ログメッセージの「MIKAGE」タブと監査ログに、相手の URL と詳しい理由がある。HTTP 5xx。ArcGIS Server のログを確かめる。 |
| E104 | サーバーが要求を受け付けない | サーバーが要求を断りました。条件の書き方、表の作り、サーバーの設定が合っていないときに起きます。 | 条件を入れたときは、条件を見直してやり直してください。続くときは、コードと時刻を管理者に伝えてください。 | ログメッセージの「MIKAGE」タブと監査ログに、相手の URL と詳しい理由がある。サーバーが返した code と message もそこにある。 |
| E105 | サーバーの応答を読めない | サーバーの答えが、MIKAGE が読める形ではありませんでした。設定の URL が別のページを指しているか、途中の装置（プロキシのサインイン画面など）が別のページを返しています。 | ブラウザで一度サインインしてから、やり直してください。続くときは、コードと時刻を管理者に伝えてください。 | ログメッセージの「MIKAGE」タブと監査ログに、相手の URL と詳しい理由がある。設定ファイルの URL とプロキシを確かめる。 |
| E106 | サーバーの応答が大きすぎる | サーバーの答えが、MIKAGE が一度に受け取れる大きさを超えました。 | 期間や範囲を狭めて、やり直してください。 | ログメッセージの「MIKAGE」タブと監査ログに、相手の URL と詳しい理由がある。 |
| E107 | オフライン中で控えなし | サーバーにつながらないため、オフライン作業中です。まだ一度も開いていない一覧は、この PC に控えがありません。 | サーバーにつながってから開き直してください。止まるのが分かっているときは、使う一覧を先に一度開いておくと、止まっている間も控えで見られます。 | docs/admin/operations.md の「サーバー障害時のオフライン作業」。 |
| E108 | 処理サービスで失敗 | サーバーの処理サービス（ArcGIS の GP サービス・OGC API の処理）が、サーバーの中で失敗しました。 | 入力（図形・値）を見直して、もう一度やり直してください。続くときは、コードと時刻を管理者に伝えてください。 | ログメッセージの「MIKAGE」タブと監査ログに、相手の URL と詳しい理由がある。サービスのジョブのメッセージもそこにある。 |
| E109 | 処理サービスとして使えない URL | 入力した URL が、MIKAGE の使える処理サービス（ArcGIS の GP サービス・GP タスク・OGC API – Processes）ではありません。 | URL を確かめてください。分からないときは管理者に聞いてください。 | ログメッセージの「MIKAGE」タブと監査ログに、相手の URL と詳しい理由がある。 |
| E110 | この PC の中の通信を始められない | この PC の中で使う通信の口（ポート）を開けませんでした。ほかのソフトか、もう 1 つの QGIS が使っています。 | MIKAGE の入った QGIS を 2 つ開いていたら、片方を閉じてください。続くときは、コードと時刻を管理者に伝えてください。 | 練習モードの練習用サーバー・AutoMap からの受け取り（shapeReceiver.port）。 |

## サインイン・権限・担当（E2xx）

| コード | 画面の表示 | 原因 | 対処（利用者） | 管理者が確かめること |
|---|---|---|---|---|
| E201 | サインインの期限切れ | サーバーへのサインインの期限が切れたか、サインインが取り消されました。 | もう一度やり直してください（MIKAGE がサインインし直します）。続くときは QGIS を再起動して、サインインし直してください。 | トークンの期限（498・499）。認証設定（authcfg）の OAuth2 の更新を確かめる。 |
| E202 | 使う権限がない | サインインした利用者に、この表を読む・書く権限がありません。 | 管理者に権限を頼んでください。 | ポータルのグループと、フィーチャ サービスの共有・編集の設定。 |
| E203 | サインインが必要 | このサーバーはサインインが必要ですが、サインインの設定がありません。 | 管理者に、サインインの設定（認証設定）を頼んでください。 | 設定ファイルの authcfg と、QGIS の認証設定。 |
| E204 | サインインの設定を使えない | QGIS のサインインの設定（認証設定）が見つからないか、QGIS のマスターパスワードが入っていません。 | QGIS がマスターパスワードを聞いてきたら入れてください。続くときは管理者に連絡してください。 | QGIS の 設定 ▸ オプション ▸ 認証。設定ファイルの authcfg の ID。 |
| E205 | 利用者名が分からない | 記録に残す利用者名を、この PC から得られませんでした。 | 管理者に連絡してください。 | 設定ファイルの editTracking.user（docs/admin/operations.md の「作成者・更新者の記録」）。 |
| E206 | この担当では使えない | ほかの担当の機能か、設定ファイルで使わないことにした機能です。 | 自分の作業なら、メニュー「担当と個人設定…」でその担当にもチェックしてください。 | 設定ファイルと、利用者の担当（TBL_USER_ROLE）。 |

## ほかの人の作業・件数（E3xx）

| コード | 画面の表示 | 原因 | 対処（利用者） | 管理者が確かめること |
|---|---|---|---|---|
| E301 | ほかの人が先に変更 | 読み込んだあとに、ほかの人が同じものを変更しました。上書きしないように、保存を止めています。 | 「最新を取得」を押してから、もう一度変更してください。 | 編集の記録（editTracking）の UPDATED_DATE で比べている。 |
| E302 | ほかの人が削除済み | 読み込んだあとに、ほかの人が同じものを削除しました。 | 「最新を取得」を押して、確かめてください。 |  |
| E303 | ほかの人が担当中 | 1 画像 1 人の決まりのとき、ほかの人がこの画像の担当になっています。 | 別の画像にするか、担当の人に「ほかの人に渡す」を頼んでください。 | 設定ファイルの分担（assignments）。 |
| E304 | 件数が上限を超えた | 一度に取得できる件数（上限）を超えたため、途中で止めました。一部だけを見せて間違えないように、何も取得していません。 | 期間・範囲・条件で絞ってから、やり直してください。古い行は管理者に整理を頼んでください。 | 上限は機能ごと（観測記録 observationStores の limit など）。 |
| E305 | サーバーが保存を受け付けない | サーバーが行の追加・変更・削除を断りました（値の長さや形、権限、ほかの人が先に削除したなど）。何件かのうちの一部のときは、ほかの行は保存されています。 | 「最新を取得」を押してから、残りをもう一度保存してください。続くときは、コードと時刻を管理者に伝えてください。 | ログメッセージの「MIKAGE」タブと監査ログに、相手の URL と詳しい理由がある。サーバーが行ごとに返した理由もそこにある。 |

## ファイル・フォルダ（E4xx）

| コード | 画面の表示 | 原因 | 対処（利用者） | 管理者が確かめること |
|---|---|---|---|---|
| E401 | ファイル・フォルダがない | 指定した場所にファイルかフォルダがありません。移動・削除されたか、共有フォルダにつながっていません。 | 場所を確かめてください。共有フォルダなら、エクスプローラーで開けるか確かめてください。 | ログに場所がある。 |
| E402 | ファイルに書き込めない（使用中・権限） | ファイルかフォルダに書き込めません。ほかのソフトで開いているか、書き込む権限がありません。 | Excel などで開いていたら閉じてから、やり直してください。直らないときは、別の場所に保存してください。 | ログに場所がある。フォルダのアクセス権。 |
| E403 | ディスクの空きがない | 保存先のディスクがいっぱいです。 | 不要なファイルを消すか、別の場所に保存してください。 |  |
| E404 | ファイルを読めない（形式が違う・壊れている） | ファイルの中身が、期待した形式ではありません。別の種類のファイルか、途中で切れたファイルです。 | 選んだファイルが正しいか確かめてください。作り直せるなら作り直してください。 | ログに理由（何行目か など）がある。 |
| E405 | 文字コードを読めない | ファイルの文字コードが、UTF-8 でも Shift_JIS でもありません。 | 表計算ソフトで「UTF-8」か「Shift_JIS」を選んで保存し直してから、取り込んでください。 |  |
| E406 | ファイルが大きすぎる | ファイルが、この操作で扱える大きさを超えています。 | 小さく分けるか、範囲を狭めてください。 |  |
| E407 | ファイルを開けない | ファイルかフォルダを開けませんでした（上のどれにも当たらない理由）。 | 場所と権限を確かめてから、やり直してください。続くときは、コードと時刻を管理者に伝えてください。 | ログに OS の理由がある。 |

## 画像（E5xx）

|---|---|---|---|---|
| E501 | 画像の場所が分からない | 画像カタログのこの行に、画像ファイルの場所が書かれていません。 | 管理者に連絡してください。ファイルのない画像として記録はできます。 | 画像カタログの表の場所の属性と、設定ファイルの catalog。 |
| E502 | 画像のフォルダが見つからない | 画像のある共有フォルダが、この PC から見つかりません。 | 「フォルダを選んで」と出たら、画像の共有フォルダを選んでください。違うフォルダを覚えてしまったら、メニュー「設定…」の「画像のフォルダの対応」で「対応を消去」してください。 | 設定ファイルの pathMappings。 |

| E504 | 画像にそのバンドがない | 使うバンド（色の層）が、この画像にありません。 | バンドの番号か、別の画像を選んでください。 | 画像補正の設定（enhance のルール）や AI のモデルのバンドの指定。 |
| E505 | 向きを直していない画像には使えない | 北が上になっていない（回転のある）画像には、この処理を使えません。 | 北が上の画像（オルソ画像など）で、やり直してください。 |  |
| E506 | 画像が重ならない | 2 つの画像の重なる所がないか、小さすぎるか、値のある画素がありません。 | 同じ場所を写した画像を選んでください。 |  |
| E507 | 画像の位置を合わせられない | 2 つの画像に、位置合わせに使える同じ模様が見つかりませんでした。 | 重なりの大きい画像か、模様（建物・道路など）のある範囲で、やり直してください。 |  |
| E508 | 画像の座標変換に失敗 | 画像の座標を、別の座標系や格子に直せませんでした。 | 画像の座標系を確かめてください。続くときは、コードと時刻を管理者に伝えてください。 | ログに理由がある。 |
| E509 | 標高データを使えない | 標高データ（ファイルかイメージサーバー）を開けない・読めないか、画像の範囲に標高データがありません。 | 画像の範囲を含む標高データを選んでください。クイック幾何補正では、地形の補正を外せば目印の点だけで直せます。続くときは、コードと時刻を管理者に伝えてください。 | 設定ファイルの dem（イメージサーバーの URL・トークン、標高ファイルのパス）。ログにサーバーの答えがある。 |
| E510 | ピラミッドを作れない | 大きな画像を速く表示するための縮小版（ピラミッド）を作れませんでした。画像はそのまま見られますが、表示が遅いままです。 | そのまま作業を続けられます。続くときは、コードと時刻を管理者に伝えてください。 | 画像の隣・キャッシュフォルダ（overviews）への書き込み権限。 |
